## How I Approach Problems

* **Start with the process:** understand the real problem before
  choosing a tool.
* **Automate deliberately:** use deterministic workflow logic where
  possible and AI where it adds value.
* **Design for clarity:** make inputs, outputs, and decisions easy to
  inspect.
* **Build for reuse:** prefer modular workflows and repeatable
  solutions over one-off fixes.
* **Measure usefulness:** value time saved, fewer errors, and a better
  user experience---not complexity for its own sake.
